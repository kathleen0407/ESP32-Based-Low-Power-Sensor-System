# Project Documentation

This folder contains the complete, detailed documentation for the ESP32 Low Power Weather Station project.

## What's Included in the Documentation?

The documentation is structured to guide you through the entire build process, from hardware assembly to final testing. It includes:

*   **01 — Overview:** Project goals, use cases, and features.
*   **02 — Hardware & Software Components:** Full list of required parts and tools.
*   **03 — Application Discussion:** How each component works together.
*   **04 — Hardware Setup:** Wiring diagrams and assembly instructions.
*   **05 — Software Setup:** IDE configuration and library installation.
*   **06 — Code:** The complete, finalized Arduino firmware broken down into logical sections.
*   **07 — Code Breakdown:** Detailed explanations of the key functions and logic.
*   **08 — Testing and Calibration:** Real-world testing results, including the successful 3.13-day battery endurance test.
*   **09 — System Demonstration:** Photos of the hardware, web dashboard, and CSV data.
*   **10 — Conclusion:** Project summary and future improvement recommendations.

## Formatting

The documentation was created using the **CreateLabz Tutorial Blog Template (v2.0)**, ensuring a responsive layout, scoped CSS, and syntax-highlighted code blocks.
